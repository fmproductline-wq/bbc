Get Started in 3 Steps

1

Download & Install Ollama (free)

Ollama is the free AI engine that runs models locally. Download it at ollama.com/download — takes 1 minute.

2

Download a Free AI Model

Open your terminal and run: ollama pull llama3.2:3b
This downloads a ~2 GB AI model. Only needed once.

3

Install or Run BestBrand AI

Install the app above (or use the portable USB version). Open it and start chatting. No internet required.
