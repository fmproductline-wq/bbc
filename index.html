Payment & Commission Setup
How your affiliate commissions are paid out.

⚡ Crypto Wallet Recommended

Bitrefill pays affiliate commissions in Bitcoin or your chosen crypto directly to your withdrawal wallet. Set your payout address in your Bitrefill affiliate dashboard.

Bitrefill Affiliate Dashboard → Settings → Payout Method → Enter BTC / ETH / USDC address → Min payout: $10 equivalent

💳 Stripe Payouts

To accept fiat payouts via Stripe, set up a Stripe Connect account and direct Bitrefill commissions through a conversion layer (e.g. your own server or a service like MoonPay).

Option A: Bitrefill → BTC → Stripe (via MoonPay / Coinbase Commerce) Option B: Bitrefill balance → wire (Enterprise accounts only)

Integration Setup Guide
Get live in under 30 minutes.

Apply for a Bitrefill Affiliate Account

Visit bitrefill.com/affiliate and apply for their affiliate program. You'll receive a unique ref code and API credentials. Bitrefill pays 1% commission instantly on every completed purchase.

Add Bitrefill MCP to Claude

Open ~/.claude/claude_desktop_config.json (or Claude Code settings) and add the Bitrefill MCP server with your affiliate code in the URL:

{ "mcpServers": { "bitrefill": { "type": "http", "url": "https://api.bitrefill.com/mcp?ref=YOUR_REF_CODE" } } }

Set Your Crypto Payout Wallet

In your Bitrefill affiliate dashboard go to Settings → Payout and enter your Bitcoin or ETH wallet address. Minimum payout threshold is $10. For Stripe: use a crypto-to-fiat bridge like MoonPay or Coinbase Commerce to convert and forward funds.

Deploy This Page

Host this index.html on your domain (GitHub Pages, Netlify, Vercel, or any static host). Update the CLAUDE_API_KEY and BITREFILL_REF placeholders in the script section below. Your AI agent will go live immediately.

Configure Your .env Keys

Add these to your .env file alongside your existing Best Brand trading bot keys:

# Bitrefill affiliate BITREFILL_API_KEY=your_api_key_here BITREFILL_REF_CODE=your_ref_code_here # Fee wallet (receives affiliate commissions) FEE_WALLET_ADDRESS=your_crypto_wallet_here # Claude AI (for agent chat) ANTHROPIC_API_KEY=your_claude_key_here # Optional: Stripe for fiat payouts STRIPE_SECRET_KEY=sk_live_...
